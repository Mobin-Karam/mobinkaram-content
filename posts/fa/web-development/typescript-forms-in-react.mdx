فرم‌ها گردش‌کارهای کوچک هستند. فرم قابل اعتماد داده‌هایش را نام‌گذاری می‌کند، در مرز درست اعتبارسنجی می‌شود و راه اصلاح خطا را روشن نشان می‌دهد.

## شکل داده ارسالی را تعریف کنید

```ts
type ProfileInput = {
  displayName: string;
  email: string;
  newsletter: boolean;
};
```

از این type برای مقدار اولیه، submit handler و payload API استفاده کنید. در این صورت تغییر نام فیلد یک refactor هدایت‌شده است.

## اعتبارسنجی را لایه‌ای انجام دهید

اعتبارسنجی کلاینت بازخورد را سریع‌تر می‌کند، اما سرور باید دوباره اعتبارسنجی کند؛ سرور مرجع پذیرش داده است. فقط به disabled بودن دکمه برای محافظت تکیه نکنید.

## دسترس‌پذیری را حفظ کنید

هر input به label نیاز دارد و خطا باید با همان input ارتباط برنامه‌ریزی‌شده داشته باشد. type امن و بازخورد روشن، هر دو برای فرمی که کاربر به آن اعتماد کند لازم‌اند.
